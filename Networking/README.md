## Networking 

Here you will find my learning journey mastering networking fundementals for cloud infrastructure via hands on projects as well as notes on theory.

## What I built 

A simple ngninx webapp, hosted on an AWS EC2 Linux instance with a custom domain purchased from cloudflare.

Features:

- EC2 Instance config with nginx web server

- Cloudflare custom domain and DNS management

- AWS security gorup, exposing ports for HTTP/HTTP traffic 

- TLS certification managed within the instance itself via certbot

- Browser accessability
